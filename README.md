# 一箭又一箭（arrow-path-game）

一个用 Python + Pygame 实现的网格箭头解谜小游戏。玩家观察箭头方向与相互阻挡关系，
按合适的顺序点击箭头，使所有箭头依次飞出棋盘。

> 本项目为福州大学《H202601 软件工程与软件工程实践》第二次个人作业，
> 开发过程中使用了 AIGC 工具辅助。作业要求见 [PRD.md](PRD.md)，测试记录见 [test.md](test.md)。

---

## 游戏简介

棋盘由若干格子组成，每个格子里有一个带方向的箭头（上 / 下 / 左 / 右），或者为空。
点击一个箭头，程序会检查它前进方向上的路径：

- 如果箭头与棋盘边界之间**没有其他箭头阻挡**，该箭头飞出棋盘并被消除；
- 如果路径上**存在其他箭头**，该箭头不能被消除，会晃动并变红作为碰撞提示，
  同时**消耗一次失误机会**；
- 清除本关全部箭头即可进入下一关；
- 失误次数耗尽时本关失败，可以重新开始。

例如下面这一行，第一个箭头朝右，但右侧仍有其他箭头，因此不能飞出：

```text
→  ·  ·  ↑  ·
```

而这一行最后一个箭头朝右，右侧没有其他箭头，因此可以飞出：

```text
↑  ·  ·  ·  →
```

### 游戏界面

游戏包含**开始界面**、**游戏界面**和**通关 / 失败界面**。游戏界面显示当前关卡、
棋盘、剩余箭头数量、剩余失误次数，以及"重新开始"按钮。

## 安装和运行方法

### 1. 获取代码

```bash
git clone <仓库地址>
cd arrow-path-game
```

### 2. 安装依赖

推荐使用虚拟环境：

```bash
python -m venv .venv
# Windows
.venv\Scripts\activate
# macOS / Linux
source .venv/bin/activate

pip install -r requirements.txt
```

`requirements.txt` 只包含一个运行依赖：`pygame-ce>=2.5.0`。

### 3. 运行游戏

```bash
python main.py
```

### 4. 运行测试

```bash
python -m unittest discover -s tests -t .
```

在没有显示设备的机器（例如远程终端）上，可以先设置无头驱动再运行测试：

```bash
# Windows
set SDL_VIDEODRIVER=dummy
# macOS / Linux
export SDL_VIDEODRIVER=dummy
```

| --- | --- |
| **鼠标左键** | 点击箭头，尝试让它飞出棋盘 |

## 关卡

游戏共 **6 关**，难度递增：

| 关卡 | 棋盘 | 箭头数 | 初始被阻挡 | 失误上限 |
| --- | :-: | :-: | :-: | :-: |
| 第 1 关 · 入门 | 4×4 | 6 | 2 | 3 |
| 第 2 关 · 顺序 | 5×5 | 8 | 4 | 3 |
| 第 3 关 · 对称 | 5×5 | 12 | 10 | 4 |
| 第 4 关 · 交错 | 6×6 | 14 | 9 | 4 |
| 第 5 关 · 密林 | 6×6 | 16 | 8 | 4 |
| 第 6 关 · 终局 | 7×7 | 18 | 10 | 5 |

每个关卡都已验证**零失误可通关**——重新开始后，若依次点掉所有"当前无阻挡"的箭头，
必定能清空棋盘，不存在无解的死锁布局。后三关由 `generator.py` 以固定随机种子生成。

除了固定关卡，游戏还能**随机生成可通关的关卡**（见下文"附加功能"）。

关卡数据定义在 `levels.py` 中，用字符串书写，便于阅读和修改：

```python
{
    "name": "第 3 关 · 对称",
    "max_mistakes": 4,
    "grid": [
        "DL.RD",
        ".....",
        ".U.U.",
        ".U.U.",
        "DL.RD",
    ],
}
```

其中 `U` / `D` / `L` / `R` 表示该方向的箭头，`.` 表示空格。

## 实现思路

### 箭头、方向与关卡的表示

方向用枚举表示，枚举的值就是该方向的行、列增量：

```python
class Direction(Enum):
    UP = (-1, 0)
    DOWN = (1, 0)
    LEFT = (0, -1)
    RIGHT = (0, 1)
```

把方向直接写成增量，路径检测时就不需要针对四个方向分别写分支，
只要沿着 `(dr, dc)` 一直走即可。

棋盘是 `R 行 × C 列` 的二维网格，每格要么是 `None`（空格），要么是一个
`Arrow(row, col, direction)`。箭头不会移动、只会被消除。

### 路径检测

这是本项目的核心，也是评分中占分最高的部分（25 分）。做法是从箭头**前一个格子**
出发，沿其方向逐格前进，直到走出棋盘：

```python
def is_path_clear(self, arrow):
    dr, dc = arrow.direction.delta
    r, c = arrow.row + dr, arrow.col + dc
    while self.in_bounds(r, c):
        if self._grid[r][c] is not None:
            return False        # 途中遇到箭头 -> 被阻挡
        r += dr
        c += dc
    return True                 # 走到棋盘外都没有遇到箭头 -> 可以飞出
```

这样写有两个好处：

1. **四个方向共用同一段代码**，不需要分别处理，减少出错；
2. **边界情况自然成立**——箭头位于边缘且朝向棋盘外时，循环条件一开始就不满足，
   直接返回 `True`，不会访问越界下标（对应测试 T03）。

### 关卡可通关性

由于箭头只会被移除、不会移动，移除一个箭头只会让其它箭头的路径变得更通畅，
绝不会反过来造成新的阻挡（单调性）。因此"反复点掉所有当前可飞出的箭头"
这一贪心策略是**完备**的：若存在零失误解法，贪心一定能找到；
若贪心卡住而棋盘非空，说明剩下箭头互相阻挡成了死锁。

`levels.py` 的 `validate_levels()` 正是用这个贪心来校验每一关，
在游戏启动时和自动化测试中都会执行，避免出现无法通关的关卡。

## 附加功能

在完成基础要求的前提下额外实现了以下功能：

| 功能 | 说明 |
| --- | --- |
| **更多关卡与关卡选择** | 6 个关卡，可在选关界面任意跳转，卡片上显示棋盘尺寸与箭头数 |
| **随机关卡生成** | `generator.py` 能生成**保证可通关**的随机关卡，不会被死锁卡住 |
| **提示** | 高亮一个当前可安全飞出的箭头，2.5 秒后自动淡出 |
| **撤销上一步** | 基于点击前快照回退；失败后也能撤销，可把致命一步撤回来 |
| **计时与星级评价** | 记录本关用时，按失误与用时计分，零失误 3 星 |
| **自动求解** | 自动逐步通关当前关卡，可随时停止 |
| **进度存档** | 通关与退出时自动存档，菜单出现"继续游戏"；读档会校验是否被篡改 |
| **音效** | 7 种音效，全部由代码合成（扫频、琶音、包络），无音频设备时自动静音 |
| **打包为可执行文件** | `build_exe.py` 一键打包成单文件 exe，附 `--selftest` 自检 |

### 随机关卡生成的可通关性

生成器采用**逆序放置**，而不是"先生成再筛选"：

> 放置第 k 个箭头时，要求它沿自身方向的路径上不含任何已放置的箭头。

于是把这些箭头按放置的**逆序**移除时，第 k 个箭头在轮到它时，棋盘上只剩下在它
之前放置的那些箭头，而它们都不在它的路径上，所以它必定可以飞出。
可解性由构造本身保证，不需要事后用求解器反复筛选。

## 打包为可执行文件

```bash
pip install pyinstaller
python build_exe.py            # 加 --clean 可先清掉上次产物
```

产物在 `dist/` 目录下（Windows 为 `一箭又一箭.exe`，约 27 MB）。

打包后可执行文件自带自检模式，用来确认产物确实能跑：

```bash
./dist/一箭又一箭.exe --selftest report.txt
```

因为 exe 是 `--windowed` 打包的、没有控制台，自检把结论写进文件：

```text
第 1 关 · 入门: 箭头 6 个, 全部清空=True, 星级=3, 得分=1000
...
随机关卡生成: (5, 5) 可加载
音效模块: SoundBank 可用=True
结果: 通过
```

## 素材来源说明

本项目未使用任何第三方美术素材、音效或关卡数据：

- 界面全部由代码绘制（矩形、三角形、文字）；
- 箭头用 `pygame.draw.polygon` 绘制；
- 音效由 `audio.py` 用 numpy 合成正弦波、扫频与琶音，仓库中不含音频文件；
- 中文文字使用操作系统自带字体（Windows 的微软雅黑 / 黑体，macOS 的苹方，
  Linux 的文泉驿或 Noto Sans CJK），按平台依次回退，仓库中不包含字体文件；
- 关卡布局为本项目自行设计或由自研生成器产出，全部经过可通关性校验。
